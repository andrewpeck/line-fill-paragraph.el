* line-fill.el

An Emacs package that splits a paragraph into one sentence per line.

** Usage

Bind ~line-fill-paragraph~ to a key, e.g.:

#+begin_src emacs-lisp
(global-set-key (kbd "M-q") #'line-fill-paragraph)
#+end_src

or e.g.

#+begin_src emacs-lisp
(define-key LaTeX-mode-map (kbd "M-q") #'line-fill-paragraph)
#+end_src

- Called normally :: splits the paragraph at point into one sentence per line.
- Called with a prefix argument (~C-u M-q~) :: falls back to the standard ~fill-paragraph~.

There is also ~line-fill-buffer~, which will step through the buffer and fill all paragraphs.

~line-fill-buffer~ is tested on some LaTeX documents but not very thoroughly---please check its output.

** Example

Before:

#+begin_example
The capybara is the largest living rodent. It is native to South America. Capybaras are highly social animals.
#+end_example

After ~M-x line-fill-paragraph~:

#+begin_example
The capybara is the largest living rodent.
It is native to South America.
Capybaras are highly social animals.
#+end_example

** Sentence boundaries

Sentences are located with ~forward-sentence~, so ~sentence-end-double-space~
decides what counts as a sentence end.  With its default value of ~t~, Emacs
only treats a period as ending a sentence when it is followed by two spaces, so
single-spaced prose is deliberately left alone.  Set it to ~nil~ if you write
with single spaces:

#+begin_src emacs-lisp
(setq sentence-end-double-space nil)
#+end_src

** Abbreviation handling

The package will not insert a line break after abbreviations such as ~e.g.~,
~i.e.~, ~n.b.~, ~c.f.~, common titles like ~Mr.~ and ~Dr.~, or single-letter
initials.  Multi-initial forms such as ~U.S.~ are handled too, while acronyms
such as ~NASA.~ still end a sentence.  It also avoids breaking after ~!~ or ~?~
that appear inside quotes or parentheses (e.g. "faster (or more!) than
expected").

The list of non-breaking abbreviations is the user option
~line-fill-non-separators~, which you can extend:

#+begin_src emacs-lisp
(add-to-list 'line-fill-non-separators "Sec.")
#+end_src

** Paragraphs that are left alone

To re-flow a paragraph, ~line-fill-paragraph~ first joins it onto a single line.
That is destructive, so it is skipped unless the paragraph both looks like prose
and would actually gain at least one line break.  This keeps ~line-fill-buffer~
from mangling markup such as LaTeX preambles and ~tabular~ environments.
